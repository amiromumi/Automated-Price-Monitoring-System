# گزارش قیمت تتر (ویندوز PowerShell)

این اسکریپت قیمت جاری USDT/IRR را از API رمزینکس دریافت کرده و گزارشی را از طریق تلگرام و اعلان محلی ویندوز ارسال می‌کند.

## تنظیمات
متغیرهای ابتدای اسکریپت را ویرایش کنید:
- BOT_TOKEN: توکن بات تلگرام شما.
- CHAT_ID: شناسه عددی (Chat ID) شما در تلگرام.
- PROXY: پراکسی SOCKS5 شما (مثلاً 'socks5://127.0.0.1:10808'). اگر نیاز نیست، خالی بگذارید.

## نحوه عملکرد
۱. دریافت داده‌های JSON از API رمزینکس.
۲. پردازش قیمت‌های خرید، فروش و درصد تغییرات ۲۴ ساعته.
۳. ارسال گزارش فرمت شده به تلگرام.
۴. نمایش اعلان (Toast) در ویندوز.

## زمان‌بندی
از Task Scheduler ویندوز برای اجرای هر ساعته این اسکریپت استفاده کنید.
مثال: ایجاد یک Task که دستور `powershell.exe -ExecutionPolicy Bypass -File C:\scripts\tether_price.ps1` را اجرا کند.
