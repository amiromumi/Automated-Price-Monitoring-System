# سیستم مانیتورینگ پیشرفته قیمت‌ها

یک پروژه اتوماسیون حرفه‌ای و ماژولار برای رصد قیمت‌های بازار به همراه تحلیل‌های پیشرفته و ارسال هشدارها به تلگرام.

## 🌟 ویژگی‌های پیشرفته

- **محدوده‌های خرید لایه‌ای:** هشدارهای چندسطحی (خرید تهاجمی، خرید معمولی، توقف خرید) بر اساس سطوح قیمتی.
- **تشخیص نوسانات شدید (Volatility):** هشدار ریزش سریع (مثلاً بیش از ۱٪ در ۱۰ دقیقه) برای جلوگیری از تصمیمات عجولانه و شناسایی کرش‌های قیمتی.
- **گزارش تحلیل روزانه:** ارسال خودکار خلاصه وضعیت در ساعت ۱۷:۰۰ شامل کمترین، بیشترین و میانگین قیمت و تحلیل روند.
- **ردیابی تاریخچه:** استفاده از دیتابیس SQLite برای ذخیره تاریخچه قیمت‌ها و محاسبات روند.
- **سیستم هوشمند جلوگیری از تکرار:** ارسال هشدار تنها هنگام تغییر وضعیت محدوده برای جلوگیری از اسپم.
- **معماری ماژولار:** قابلیت گسترش آسان برای دارایی‌های مختلف و سیستم‌عامل‌های دیگر.

## 🏗️ معماری سیستم

```text
Ramzinex REST API --> اسکریپت‌های Bash/Python --> دیتابیس SQLite (تاریخچه)
                                       |
                                       +--> Telegram Bot API (هشدارها/گزارش‌ها)
                                       +--> notify-send (اعلان‌های محلی)
```

## 🛠️ تکنولوژی‌های مورد استفاده

- **زبان:** Bash / Shell scripting
- **پردازش داده:** Python 3
- **دیتابیس:** SQLite3 (برای تحلیل‌های تاریخی)
- **شبکه:** `curl` / HTTP REST
- **زمان‌بندی:** Linux Cron
- **اعلان‌ها:** Telegram Bot API / `libnotify`

## 🚀 شروع سریع

### ۱. کلون کردن و نصب
```bash
git clone https://github.com/amiromumi/Automated-Price-Monitoring-System.git
cd Automated-Price-Monitoring-System
cd Linux/usdt
mkdir -p "$HOME/Scripts"
cp *.sh "$HOME/Scripts/"
chmod +x "$HOME/Scripts/"*.sh
```

### ۲. پیکربندی
اسکریپت‌های موجود در `~/Scripts/` را ویرایش کرده و مقادیر `YOUR_BOT_TOKEN` و `YOUR_CHAT_ID` را جایگزین کنید.

### ۳. زمان‌بندی
برای دستورالعمل‌های دقیق، به [راهنمای جامع تنظیم Cron](docs/LINUX_CRON_SETUP-fa.md) مراجعه کنید.
