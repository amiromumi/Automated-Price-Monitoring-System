# سیستم خودکار مانیتورینگ قیمت‌ها (Automated Price Monitoring System)

یک سیستم حرفه‌ای و ماژولار برای رصد لحظه‌ای قیمت دارایی‌ها و ارسال هشدارهای خودکار از طریق تلگرام و نوتیفیکیشن‌های دسکتاپ. این پروژه نمونه‌ای از ترکیب اتوماسیون سیستم (Cron)، مصرف APIها و ارسال اعلان‌های چندکاناله است.

## 🚀 ویژگی‌های کلیدی
- **رصد لحظه‌ای**: دریافت داده‌های زنده از APIهای معتبر صرافی‌ها.
- **اعلان‌های دوگانه**: ارسال هشدارها همزمان از طریق بات تلگرام و نوتیفیکیشن‌های بومی لینوکس (`libnotify`).
- **زمان‌بندی خودکار**: اجرای کاملاً مستقل با استفاده از `cron` برای مانیتورینگ بدون نیاز به دخالت کاربر.
- **معماری ماژولار**: ساختاری منعطف برای پشتیبانی آسان از دارایی‌های جدید (طلا، بیت‌کوین، اتریوم) و سیستم‌عامل‌های مختلف (لینوکس، ویندوز).

## 📂 ساختار پروژه
```
.
├── Linux/               # پیاده‌سازی‌های لینوکس
│   └── usdt/            # مجموعه مانیتورینگ تتر (USDT)
│       ├── tether_price.sh  # گزارش‌دهنده ساعتی قیمت
│       ├── tether_alert.sh  # مانیتور محدوده خرید (Buy-zone)
│       └── README.md        # مستندات دقیق دارایی
├── Windows/             # پیاده‌سازی‌های ویندوز (در حال برنامه‌ریزی)
├── README.md            # مستندات اصلی (انگلیسی)
└── README-fa.md         # مستندات اصلی (فارسی)
```

## 🛠️ تکنولوژی‌های مورد استفاده
- **زبان**: Bash / Shell Scripting
- **زمان‌بندی**: Cron (Linux)
- **APIها**: REST APIs (JSON)
- **اعلان‌ها**: Telegram Bot API, `notify-send` (libnotify)

## ⚡ شروع سریع (لینوکس - تتر)

برای راه‌اندازی سریع مانیتور تتر:

۱. **کلون کردن مخزن** و ورود به پوشه تتر:
   `cd Linux/usdt`
۲. **آماده‌سازی اسکریپت‌ها**:
   `mkdir -p ~/scripts && cp tether_*.sh ~/scripts/ && chmod +x ~/scripts/tether_*.sh`
۳. **تنظیمات**: اسکریپت‌ها را باز کرده و `BOT_TOKEN` و `CHAT_ID` خود را وارد کنید.
۴. **زمان‌بندی**:
   - برای آپدیت ساعتی: خط `0 * * * * /home/yourusername/scripts/tether_price.sh` را به `crontab -e` اضافه کنید.
   - برای هشدار محدوده خرید: خط `*/2 * * * * /home/yourusername/scripts/tether_alert.sh` را به `crontab -e` اضافه کنید.

برای راهنمای کامل، لطفاً به فایل `Linux/usdt/README.md` مراجعه کنید.
