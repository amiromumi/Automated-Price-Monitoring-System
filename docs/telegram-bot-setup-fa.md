# راهنمای راه‌اندازی بات تلگرام

این راهنما به‌صورت گام‌به‌گام نحوه ساخت بات تلگرام و گرفتن Chat ID را توضیح می‌دهد. تمام اسکریپت‌های این پروژه برای ارسال اعلان به این دو مقدار نیاز دارند.

[English documentation](telegram-bot-setup.md)

## گام ۱: ساخت بات

۱. اپلیکیشن تلگرام را باز کنید (موبایل یا دسکتاپ).
۲. **@BotFather** را جستجو کنید — مطمئن شوید تیک آبی تأیید دارد.
۳. یک گفت‌وگو باز کنید و `/newbot` را بفرستید.
۴. BotFather یک **نام نمایشی** می‌خواهد — هر چیزی دوست دارید بنویسید (مثلاً `مانیتور قیمت من`).
۵. BotFather یک **نام کاربری** می‌خواهد — باید به `bot` ختم شود (مثلاً `my_price_monitor_bot`).
۶. BotFather پیامی می‌فرستد که شامل **توکن بات** شماست. چیزی شبیه این:

   ```
   1234567890:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

۷. این توکن را کپی و در جای امن نگه دارید. این همان `BOT_TOKEN` شماست.

## گام ۲: گرفتن Chat ID

بات باید بداند پیام را به کدام گفت‌وگو بفرستد. Chat ID شخصی شما یک عدد است.

۱. در تلگرام، **@userinfobot** را جستجو کنید (یا **@getmyId_bot** به‌عنوان جایگزین).
۲. هر پیامی بفرستید (مثلاً `hi`).
۳. این بات اطلاعات حساب شما را می‌فرستد. عدد کنار **Id** (یا **Your user ID**) همان `CHAT_ID` شماست.

## گام ۳: استارت زدن بات (الزامی)

بات تلگرام **تا زمانی که شما یک‌بار گفت‌وگو را شروع نکرده باشید** نمی‌تواند برایتان پیام بفرستد:

۱. در تلگرام، باتی که ساختید را با نام کاربری‌اش جستجو کنید.
۲. گفت‌وگو را باز کنید و دکمه **Start** را بزنید (یا `/start` بفرستید).
۳. باید پیام تأیید از بات ببینید.

اگر این گام را انجام ندهید، اسکریپت‌ها از API پاسخ `ok:true` دریافت می‌کنند اما هیچ پیامی در تلگرام خود دریافت نخواهید کرد.

## گام ۴: تست (اختیاری اما توصیه‌شده)

ترمینال را باز کنید و بات را مستقیماً تست کنید:

```bash
curl -s "https://api.telegram.org/botYOUR_BOT_TOKEN/sendMessage" \
  -d "chat_id=YOUR_CHAT_ID" \
  --data-urlencode "text=Hello from my monitor!"
```

به جای `YOUR_BOT_TOKEN` و `YOUR_CHAT_ID` مقادیر واقعی خود را بنویسید.

**نتیجه مورد انتظار:** ترمینال یک پاسخ JSON شامل `"ok":true` چاپ می‌کند و پیام تست در تلگرام شما می‌رسد.

### اگر تلگرام روی شبکه شما فیلتر است

گزینه پراکسی را به دستور اضافه کنید:

```bash
curl -s --proxy "socks5h://127.0.0.1:10808" \
  "https://api.telegram.org/botYOUR_BOT_TOKEN/sendMessage" \
  -d "chat_id=YOUR_CHAT_ID" \
  --data-urlencode "text=Hello from my monitor!"
```

به جای `127.0.0.1:10808` آدرس و پورت پراکسی خود را بنویسید.

## گام ۵: وارد کردن مقادیر در اسکریپت‌ها

هر اسکریپتی که به `~/scripts/` کپی کرده‌اید را باز کنید و بخش تنظیمات را پیدا کنید:

```bash
nano ~/scripts/tether_price.sh
nano ~/scripts/tether_alert.sh
```

مقادیر زیر را جایگزین کنید:

```bash
BOT_TOKEN="YOUR_BOT_TOKEN"
CHAT_ID="YOUR_CHAT_ID"
```

با توکن و Chat ID واقعی خود. ذخیره کنید و خارج شوید.

## نکات امنیتی

- توکن واقعی بات یا Chat ID را هرگز در Git کامیت نکنید.
- اسکریپت‌های مخزن عمداً از مقادیر نمونه (Placeholder) استفاده می‌کنند.
- اگر توکن شما عمومی شد، فوراً آن را باطل کنید:
  - تلگرام را باز کنید، **@BotFather** را پیدا کنید، `/revoke` یا `/token` را بفرستید، بات خود را انتخاب کنید و توکن جدید بسازید. توکن قدیمی بلافاصله غیرفعال می‌شود.
- برای محیط عملیاتی، اطلاعات حساس را در فایل جداگانه با دسترسی `chmod 600` نگهداری کنید.
