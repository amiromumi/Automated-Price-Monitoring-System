# راهنمای تنظیمات دیتابیس

این پروژه از **SQLite3** استفاده می‌کند؛ یک دیتابیس سبک و فایل‌محور که برای ردیابی تاریخچه قیمت‌ها و تحلیل روندها به کار می‌رود.

## 🛠️ معماری
دیتابیس به صورت یک تک‌فایل با نام `price_history.db` ذخیره می‌شود. این دیتابیس نیازی به سرور ندارد و مستقیماً توسط اسکریپت‌های Bash مدیریت می‌شود.

## 📊 ساختار (Schema)
دیتابیس شامل یک جدول به نام `history` با ساختار زیر است:

| ستون | نوع | توضیحات |
|---|---|---|
| `timestamp` | DATETIME | تاریخ و ساعت دقیق ثبت قیمت (پیش‌فرض: زمان فعلی) |
| `price` | REAL | قیمت خرید USDT/IRR |

## 🚀 نحوه عملکرد
۱. **جمع‌آوری داده‌ها:** هر بار که اسکریپت `tether_alert.sh` اجرا می‌شود، قیمت فعلی را در جدول `history` درج می‌کند.
۲. **تحلیل:** اسکریپت `tether_daily_report.sh` و منطق تشخیص نوسانات، از کوئری‌های SQL برای محاسبه `MIN()` (کمترین)، `MAX()` (بیشترین) و `AVG()` (میانگین) قیمت‌ها در بازه‌های زمانی خاص (مثلاً ۲۴ ساعت اخیر یا ۱۰ دقیقه اخیر) استفاده می‌کنند.

## 💻 کوئری‌های کاربردی SQL
اگر می‌خواهید داده‌ها را به صورت دستی بررسی کنید، می‌توانید از ابزار `sqlite3` در ترمینال استفاده کنید:

**مشاهده ۱۰ رکورد آخر:**
```bash
sqlite3 /home/yourusername/Scripts/price_history.db "SELECT * FROM history ORDER BY timestamp DESC LIMIT 10;"
```

**محاسبه میانگین قیمت امروز:**
```bash
sqlite3 /home/yourusername/Scripts/price_history.db "SELECT AVG(price) FROM history WHERE timestamp >= date('now');"
```

## ⚙️ راه‌اندازی
دیتابیس به صورت خودکار در اولین اجرای اسکریپت‌ها ساخته می‌شود. با این حال، می‌توانید از اسکریپت `init_db.sh` برای ایجاد دستی آن استفاده کنید.
