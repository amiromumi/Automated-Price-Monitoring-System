# راهنمای تنظیم Cron در لینوکس

این راهنما دستورالعمل‌های دقیق برای زمان‌بندی اسکریپت‌های مانیتورینگ قیمت با استفاده از سرویس native cron در لینوکس را ارائه می‌دهد.

## ۱. Cron چیست؟
کرون (Cron) یک زمان‌بند وظایف (Job Scheduler) در سیستم‌های یونیکسی است که به شما اجازه می‌دهد اسکریپت‌ها را در فواصل زمانی مشخص به صورت خودکار اجرا کنید.

## ۲. دسترسی به Crontab
برای ویرایش وظایف زمان‌بندی شده کاربر خود، دستور زیر را در ترمینال اجرا کنید:
```bash
crontab -e
```
*اگر از شما خواسته شد ویرایشگری را انتخاب کنید، برای سادگی `nano` را پیشنهاد می‌کنیم.*

## ۳. زمان‌بندی اسکریپت‌ها
خطوط زیر را به انتهای فایل crontab خود اضافه کنید. **به جای `yourusername` نام کاربری لینوکس خود (مثلاً `amiromumi`) را قرار دهید.**

### گزارش ساعتی قیمت
ارسال به‌روزرسانی قیمت هر ساعت یک‌بار.
```cron
0 * * * * /home/yourusername/Scripts/tether_price.sh >> /home/yourusername/Scripts/price_log.log 2>&1
```

### مانیتورینگ هر ۲ دقیقه (منطقه خرید)
بررسی قیمت هر ۲ دقیقه یک‌بار و ارسال هشدار فقط در صورت ورود یا خروج از محدوده خرید.
```cron
*/2 * * * * /home/yourusername/Scripts/tether_alert.sh >> /home/yourusername/Scripts/alert_log.log 2>&1
```

## ۴. درک سینتکس Cron
هر ورودی کرون از پنج فیلد زمانی و سپس دستور اجرا تشکیل شده است:
`* * * * * command`
- **دقیقه (۰-۵۹):** `*/2` یعنی هر ۲ دقیقه یک‌بار.
- **ساعت (۰-۲۳):** `0` یعنی دقیقاً در شروع ساعت.
- **روز ماه (۱-۳۱):** `*` یعنی هر روز.
- **ماه (۱-۱۲):** `*` یعنی هر ماه.
- **روز هفته (۰-۶):** `*` یعنی هر روز هفته.

## ۵. ثبت لاگ و عیب‌یابی
بخش `>> /path/to/log 2>&1` بسیار حیاتی است. این دستور باعث می‌شود تمام خروجی‌های استاندارد و پیام‌های خطا در یک فایل ذخیره شوند تا در صورت اجرا نشدن اسکریپت، دلیل آن را بدانید.

برای مشاهده لحظه‌ای اجرای اسکریپت‌ها، از دستور زیر استفاده کنید:
```bash
tail -f ~/Scripts/price_log.log
```

## ۶. نکات مهم
- **مسیرهای مطلق (Absolute Paths):** همیشه از مسیر کامل استفاده کنید (مثلاً `/home/user/script.sh` به جای `~/script.sh`) زیرا کرون در محیط محدودی اجرا می‌شود و ممکن است مسیرهای نسبی را نشناسد.
- **سطح دسترسی:** مطمئن شوید اسکریپت‌ها قابلیت اجرا دارند:
  ```bash
  chmod +x ~/Scripts/*.sh
  ```
- **پایداری:** جاب‌های کرون بعد از ریبوت سیستم باقی می‌مانند. اما توجه داشته باشید که اگر سیستم در حالت Hibernate باشد، جاب‌هایی که در آن بازه زمانی تعریف شده‌اند اجرا نمی‌شوند.
