# پیاده‌سازی‌های لینوکس (Linux Implementations)

این پوشه شامل پیاده‌سازی‌های مخصوص سیستم‌عامل لینوکس است. تمرکز اصلی در اینجا بر استفاده از ابزارهای بومی لینوکس مانند `cron` برای زمان‌بندی و `libnotify` برای ارسال اعلان‌های سیستمی است.

## 📂 دارایی‌های فعلی
در حال حاضر، دارایی‌های زیر برای لینوکس پیاده‌سازی شده‌اند:
- **تتر (USDT)**: مجموعه کامل مانیتورینگ شامل گزارش‌دهنده‌های ساعتی و هشدارهای مبتنی بر محدوده قیمت. برای جزئیات بیشتر به [`Linux/usdt/README.md`](./usdt/README.md) مراجعه کنید.

## 🛠️ رویکرد پیاده‌سازی در لینوکس
برای تمام دارایی‌های موجود در این پوشه، از یک معماری یکپارچه استفاده شده است:
۱. **اسکریپت‌نویسی شل**: استفاده از فایل‌های `.sh` برای بیشترین سازگاری و کمترین مصرف منابع.
۲. **اتوماسیون**: بهره‌گیری از `crontab` سیستم برای اطمینان از اینکه مانیتورینگ به صورت یک دیمون (Daemon) در پس‌زمینه اجرا شود و نیازی به باز بودن ترمینال نباشد.
۳. **سیستم اعلان**:
   - **دور (Remote)**: یکپارچه‌سازی با API بات تلگرام از طریق `curl`.
   - **محلی (Local)**: یکپارچه‌سازی با `notify-send` برای ارائه بازخورد بصری فوری روی دسکتاپ کاربر.

## 🚀 شروع سریع
برای استقرار هر دارایی از این پوشه:
۱. اسکریپت‌های دارایی مورد نظر را به یک پوشه پایدار محلی (مثلاً `~/scripts/`) منتقل کنید.
۲. اطمینان حاصل کنید که اسکریپت‌ها دسترسی اجرایی دارند (`chmod +x`).
۳. اعتبارنامه‌های API (توکن و چت آی‌دی) را در اسکریپت‌ها تنظیم کنید.
۴. ورودی‌های مربوط به cron را به `crontab` خود اضافه کنید.
