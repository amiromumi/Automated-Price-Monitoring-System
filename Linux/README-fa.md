# پیاده‌سازی لینوکس

این پوشه شامل لایه اتوماسیون مخصوص لینوکس پروژه است.

[English documentation](README.md)

## ماژول فعلی

- [مانیتور USDT](usdt/README-fa.md): گزارش زمان‌بندی‌شده قیمت و هشدار محدوده خرید مبتنی بر تغییر وضعیت.

## پیش‌نیازها

نمونه برای Debian/Ubuntu:

```bash
sudo apt update
sudo apt install -y curl python3 libnotify-bin cron
```

در توزیع‌های دیگر، بسته‌های معادل را با Package Manager همان توزیع نصب کنید.

## مسیر پیشنهادی فایل‌ها

نسخه اجرایی اسکریپت‌ها را در یک مسیر پایدار متعلق به کاربر نگه دارید:

```bash
mkdir -p "$HOME/scripts"
cp usdt/tether_price.sh usdt/tether_alert.sh "$HOME/scripts/"
chmod +x "$HOME/scripts/tether_price.sh" "$HOME/scripts/tether_alert.sh"
```

در دستورهای زمان‌بندی‌شده از مسیر مطلق استفاده کنید. Cron ممکن است متغیرهای محیطی را گسترش ندهد یا `PATH` آن با ترمینال تعاملی متفاوت باشد.

## Cron استاندارد لینوکس

Crontab کاربر فعلی را باز کنید:

```bash
crontab -e
```

خطوط زیر را اضافه کنید:

```cron
0 * * * * /home/yourusername/scripts/tether_price.sh
*/2 * * * * /home/yourusername/scripts/tether_alert.sh
```

بررسی تنظیمات:

```bash
crontab -l
systemctl status cron
```

وقتی کامپیوتر Suspend است، جاب‌های معمولی اجرا نمی‌شوند. بسته به زمان‌بند، اجرای ازدست‌رفته ممکن است بعد از Resume با تأخیر انجام شود یا کاملاً از دست برود. قفل شدن نمایشگر با Suspend متفاوت است؛ در حالت قفل ساده معمولاً جاب‌ها ادامه دارند.

## اعلان دسکتاپ

`notify-send` باید به نشست گرافیکی فعال دسترسی داشته باشد. ممکن است دستور در ترمینال موفق باشد اما در Cron به علت نبود `DISPLAY`، `DBUS_SESSION_BUS_ADDRESS` یا نشست گرافیکی، اعلان را بی‌صدا نمایش ندهد. ارسال تلگرام مستقل از اعلان دسکتاپ است.

اگر اعلان دسکتاپ از Cron قابل اعتماد نبود، می‌توان از سرویس و Timer سطح کاربر `systemd` که به نشست گرافیکی متصل است استفاده کرد. تلگرام همچنان کانال مطمئن هشدار راه دور خواهد بود.

## زمان‌بند اختیاری Hermes

برای اجرای پروژه به Hermes Agent نیازی نیست. اگر به جای Cron سیستم از Hermes cron استفاده می‌کنید، Hermes Gateway باید فعال بماند:

```bash
hermes gateway install --start-now --start-on-login
hermes gateway status
hermes cron status
```

برای اجرای اسکریپت بدون هزینه مدل از جاب `no_agent` استفاده کنید. وقتی خود اسکریپت پیام تلگرام را ارسال می‌کند، تحویل محلی زمان‌بند کافی است؛ مسئول ارسال پیام خود اسکریپت است.

## چک‌لیست عملیاتی

- اسکریپت‌ها در اجرای دستی بدون خطا کار می‌کنند.
- اطلاعات واقعی فقط در نسخه محلی هستند و وارد Git نشده‌اند.
- در صورت تنظیم پراکسی، سرویس پراکسی فعال است.
- سرویس زمان‌بند فعال است.
- مسیرهای مطلق استفاده شده‌اند.
- سیستم در زمان اجرا Suspend نیست.
- کانال تلگرام و اعلان دسکتاپ جداگانه آزمایش شده‌اند.

برای تنظیمات، زمان‌بندی، تست و عیب‌یابی کامل، [راهنمای USDT](usdt/README-fa.md) را ببینید.
