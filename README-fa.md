# سیستم مانیتورینگ خودکار قیمت‌ها

یک پروژه اتوماسیون سبک و ماژولار برای مانیتورینگ قیمت‌های بازار و ارسال هشدارها به تلگرام و اعلان‌های دسکتاپ لینوکس. در حال حاضر این سیستم قیمت USDT/IRR را از طریق API عمومی Ramzinex رصد می‌کند و به گونه‌ای طراحی شده که دارایی‌ها و سیستم‌عامل‌های دیگر را بتوان به راحتی به آن اضافه کرد.

## ویژگی‌ها

- قیمت‌های لحظه‌ای خرید/فروش USDT و درصد تغییرات ۲۴ ساعته
- گزارش‌های زمان‌بندی شده قیمت
- مانیتورینگ قابل تنظیم برای منطقه خرید (Buy-Zone)
- ارسال اعلان از طریق Telegram Bot API
- اعلان‌های دسکتاپ لینوکس از طریق `notify-send`
- سیستم جلوگیری از ارسال پیام تکراری (فقط هنگام تغییر وضعیت منطقه خرید)
- پیاده‌سازی سبک با Bash و Python بدون وابستگی به LLM
- ساختار پوشه‌بندی ماژولار بر اساس `سیستم-عامل/دارایی`

## معماری سیستم

```text
Ramzinex REST API
        |
        v
اسکریپت‌های Bash + پردازش JSON با پایتون
        |
        +--> Telegram Bot API (هشدار راه دور)
        |
        +--> notify-send (هشدار دسکتاپ محلی)
        |
        +--> فایل وضعیت محلی (جلوگیری از تکرار هشدار)
```

## تکنولوژی‌های مورد استفاده

- Bash / Shell scripting
- Python 3 برای پردازش JSON
- `curl` برای درخواست‌های HTTP
- زمان‌بندی سازگار با Cron
- Telegram Bot API
- `libnotify` / `notify-send`

## شروع سریع

### ۱. کلون کردن مخزن
```bash
git clone https://github.com/amiromumi/Automated-Price-Monitoring-System.git
cd Automated-Price-Monitoring-System
```

### ۲. تنظیم بات تلگرام
قبل از استفاده از اسکریپت‌ها، به توکن بات و Chat ID نیاز دارید. [راهنمای تنظیم بات تلگرام](docs/telegram-bot-setup-fa.md) را دنبال کنید.

### ۳. نصب و پیکربندی
```bash
cd Linux/usdt
mkdir -p "$HOME/Scripts"
cp tether_price.sh tether_alert.sh "$HOME/Scripts/"
chmod +x "$HOME/Scripts/tether_price.sh" "$HOME/Scripts/tether_alert.sh"
```
هر دو اسکریپت کپی شده را ویرایش کرده و مقادیر `YOUR_BOT_TOKEN` و `YOUR_CHAT_ID` را جایگزین کنید.

### ۴. تست
```bash
bash "$HOME/Scripts/tether_price.sh"
bash "$HOME/Scripts/tether_alert.sh"
```

### ۵. زمان‌بندی (Scheduling)
برای دستورالعمل‌های دقیق و گام‌به‌گام در مورد تنظیم زمان‌بندی در لینوکس، لطفاً به [راهنمای جامع تنظیم Cron](docs/LINUX_CRON_SETUP-fa.md) مراجعه کنید.

## رفتار اعلان‌ها

- `tether_price.sh` در هر بار اجرا یک گزارش قیمت ارسال می‌کند.
- `tether_alert.sh` در هر اجرا قیمت را چک می‌کند اما هشدار خرید را فقط زمانی ارسال می‌کند که قیمت از خارج منطقه خرید به داخل آن تغییر کند. همچنین هنگام خروج از منطقه خرید، پیام خروج ارسال می‌کند.
- اعلان‌های تلگرام تا زمانی که دستگاه روشن و متصل به شبکه باشد ارسال می‌شوند.
- اعلان‌های دسکتاپ نیازمند یک نشست فعال گرافیکی (GUI Session) هستند.

## امنیت

- هرگز توکن بات، Chat ID یا کلیدهای API واقعی را در مخزن کامیت نکنید.
- اسکریپت‌های موجود در ریپوزیتوری را با مقادیر Placeholder نگه دارید.
- در صورت افشای توکن تلگرام، فوراً آن را لغو و توکن جدید دریافت کنید.
- فایل‌های پیکربندی محلی را با دستور `chmod 600` محدود کنید.

۱. اسکریپت را به صورت دستی اجرا کرده و کد خروج آن را بررسی کنید.

۳. توکن بات و Chat ID را تایید کنید.
۴. بررسی کنید که سرویس scheduler فعال است.
